# BC-Housing Affordability
An expoloritory analysis on the BC Housing Market.
Goal: To figure out which B.C. cities are affordable for a median-income household currently, and how would the next interest-rate move change that.
Description: The Dataset contains a list of houses and condos for each city by its price, interest rate and mortage payment percent income(mppi). 
The project includes the following steps: data loading, data cleaning and preprocessing, EDA (exploratory data analysis), analyzing sales data and prediction testing.
Skills:  data cleaning, data analysis, prediction testing, data visualization.
Technologies, Python, Pandas, SQL
Result: As of Q2 2026, the safest targets that are affordable for a median income household are Dawson Creek, Fort St. John and Trail, plus condos in Kamloops, Vernon and Kelowna both stay under 30% of income even if rates rise 0.5 points. Affordability overall has improved since 2022 mainly because interest rates fell and incomes rose, not because prices dropped. The October 2026 rate hike is enough to push Victoria condos and Prince George detached homes over the 30% line for the MPPI.
